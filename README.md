# Planner Bot + Админ-панель

Telegram-бот принимает задачи от главного менеджера (**текстом или голосом**,
EN / UZ / микс), определяет **направление** (лист) и дописывает строку в
соответствующий лист журнала Planner (Google Sheets). Все настройки задаются
через **веб-админку** и применяются к боту **без перезапуска**.

---

## Состав

- **Бот** (`bot.py`) — Telegram, распознавание, запись в Sheets.
- **Админ-панель** (`admin/`) — FastAPI, управление всеми настройками и логами.
- **Общее хранилище** (`settings_store.py`) — `data/settings.json`, единый
  источник настроек для бота и панели. Бот перечитывает файл при изменении
  (по mtime), поэтому правки применяются мгновенно.

```
planner-bot/
├── bot.py                 # Телеграм-бот
├── config.py              # Динамический доступ к настройкам
├── nlp.py                 # Распознавание речи + разбор задачи (OpenAI)
├── sheets.py              # Запись в Google Sheets (+ тест связи)
├── settings_store.py      # Хранилище настроек (data/settings.json)
├── event_log.py           # Логи событий (logs/events.jsonl) + чтение bot.log
├── admin/
│   ├── app.py             # FastAPI приложение
│   ├── auth.py            # Логин, хеш пароля, сессии
│   ├── templates/         # HTML-шаблоны (простые, без стороннего дизайна)
│   └── static/style.css   # Минимальные функциональные стили
├── data/                  # settings.json, секрет сессий (создаётся сам)
├── logs/                  # events.jsonl, bot.log
├── requirements.txt
├── .env.example
├── planner-bot.service    # systemd: бот
├── planner-admin.service  # systemd: панель
└── README.md
```

## Что настраивается в панели (динамически)

- **Telegram и доступы:** токен бота, whitelist Telegram ID (кто может ставить
  задачи), ключ OpenAI.
- **Google Sheets:** имя таблицы, путь к `google-creds.json` **или загрузка
  файла кредов** через панель, кнопка «Проверить подключение» (показывает
  реальные листы таблицы).
- **Поведение:** подтверждение перед записью (вкл/выкл), статус новой задачи,
  таймзона.
- **Направления (листы):** добавление/удаление направлений, имя листа,
  постоянный исполнитель (Staff Name), алиасы для распознавания.
- **Учётная запись:** смена логина/пароля админа.
- **Логи:** журнал событий (задачи, отмены, входы, изменения настроек, отказы
  доступа, ошибки) с фильтрами + технический лог бота.

Любое изменение сразу применяется к работающему боту — перезапуск не нужен.

## Установка

```bash
cd planner-bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # задайте ADMIN_USERNAME / ADMIN_PASSWORD / ADMIN_PORT
```

### Запуск админ-панели

```bash
python -m uvicorn admin.app:app --host 0.0.0.0 --port 8000
```

Откройте `http://СЕРВЕР:8000`, войдите под логином/паролем из `.env`
(при первом старте создаётся администратор). **Сразу смените пароль** в разделе
«Учётная запись».

### Первичная настройка через панель

1. **Telegram и доступы** — вставьте токен бота (от @BotFather), впишите
   Telegram ID менеджеров (узнать свой — у @userinfobot), сохраните ключ OpenAI.
2. **Google Sheets** — укажите имя таблицы и загрузите `google-creds.json`
   (или укажите путь к нему). Нажмите «Проверить подключение» — панель покажет
   листы таблицы. Не забудьте дать сервисному email из кредов доступ «Редактор»
   к таблице.
3. **Направления** — добавьте все листы (IT, HR, QA и т.д.), точно как названы
   вкладки, с исполнителями и алиасами.
4. **Поведение** — при необходимости поменяйте статус/таймзону/подтверждение.

### Запуск бота

```bash
python bot.py
```

Бот возьмёт токен и все настройки из хранилища, заполненного через панель.

## Автозапуск на сервере (systemd)

Два сервиса — бот и панель:

```bash
# отредактируйте YOUR_USER и пути в обоих .service
sudo cp planner-bot.service planner-admin.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now planner-admin
sudo systemctl enable --now planner-bot
```

Логи сервисов: `journalctl -u planner-bot -f` / `journalctl -u planner-admin -f`.

> Панель слушает порт 8000 на всех интерфейсах. В проде закройте порт файрволом
> и открывайте только через VPN или обратный прокси (nginx) с HTTPS.

## Использование бота

Менеджер пишет боту:
- `IT: reinstall Jamf profiles, deadline tomorrow`
- `Ta'minot uchun: kartridjlarni buyurtma qilish, ertaga`
- `HR: update onboarding checklist, keyingi hafta`
- голосом — то же самое.

Если направление не распознано — бот предложит выбрать лист кнопками. Если
включено подтверждение — покажет собранную задачу и кнопки **✅ Записать /
❌ Отмена**, и запишет в таблицу только после подтверждения.

---

## Логи

- **Журнал событий** — `logs/events.jsonl`, просмотр и фильтры в разделе «Логи».
  Пишутся: создание/отмена задач, входы в панель, изменения настроек, отказы
  доступа, ошибки.
- **Технический лог бота** — `logs/bot.log`, хвост виден в панели.

## Безопасность

- Пароль админа хранится хешем (PBKDF2), сессии подписаны (HMAC).
- `data/settings.json` содержит токены и ключи — доступ к серверу/файлу
  ограничьте. Он в `.gitignore`.
- Whitelist Telegram ID обязателен: без него бот примет задачу от кого угодно.
- Панель за пределами localhost открывайте только через VPN/HTTPS-прокси.

## Диагностика

| Симптом | Решение |
|---------|---------|
| В панель не пускает | Логин/пароль из `.env` (первый старт). Смените в «Учётная запись». |
| Бот: «Не задан токен» | Впишите токен в разделе «Telegram и доступы». |
| «Лист X не найден» | Имя направления не совпадает с вкладкой. Проверьте в «Проверить подключение». |
| Google: ошибка связи | Дали доступ сервисному email? Верное имя таблицы и путь к кредам? |
| Изменения не применились | Они применяются сразу; проверьте, что сохранили форму (сообщение «Сохранено»). |

Логи: раздел «Логи» в панели или `tail -n 50 logs/bot.log`.
